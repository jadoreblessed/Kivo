# KIVO implementation status

The portable package can create a fixed-supply Token-2022 mint through the user's wallet on devnet or mainnet. It stores name and ticker onchain, optionally stores a metadata JSON URI, creates the creator's token account, mints the full supply, and revokes mint authority. The token's mint address is its CA.

The admin route can persist a verified mainnet token mint address and an X profile using an external Redis REST database. It requires the four server environment values documented in `.env.example`; admin functions cannot work without these values. CA publishing is distinct from mint creation.

The deployed public site still shows an older build. In this source tree, the launch, trading, graduation and market catalogue pages are wired to the onchain program when its program ID, network and treasury are configured. The program was deployed to devnet on 2026-10-04 at `7rJ2978K9SpqB4d7FAGrquhC7Gy2iJehxB4EohDZEB8`; `solana program show` confirmed the upgrade authority `84HCJtzmvWF2tB4SCr8hmDymLN4Rz6u8jJoyaqwLjSRR` and a 442752-byte program data account. It is not deployed to mainnet. Browser wallet flows still need a live cluster rehearsal and an independent security review before any real funds flow through a market.

## Contract work in progress

`programs/kivo-market` now contains a **local prototype** for market initialization, buys, sells, claims of accrued creator and treasury trading fees, atomic migration into a permanently locked Meteora DAMM v2 position, and collection of post-migration pool fees. The pool swap fee is fixed at 1% in the tested build, with Meteora's protocol share applied by DAMM. The remaining collectible SOL fee splits by the creator percentage chosen at launch (0–80%, 50% default); the rest goes to the KIVO treasury. `programs/kivo-market-math` contains integer quote calculations for the five rules and ten price tranches. Six math tests pass. The program has passed local validator tests for mint authority revocation, buying with burn, pot payout, guard rejection, selling, fee claims, the full-curve migration, an actual Meteora swap, and post-migration fee collection and claims, including a configured 65/35 split. The graduation test checks pool token and SOL balances, the position NFT owner, zero unlocked liquidity, the exact permanently locked liquidity and source account cleanup. The example program ID is not a production deployment.

The source now also includes up to four immutable creator fee recipients, onchain blueprint publication and a royalty of 0–10% of LP/pot contributions. The UI can select published rules, and the program reserves accrued royalties during pool migration for the blueprint author to claim. On 2026-10-04 the **current** KIVO program compiled as SBF, seven math tests passed, and the local validator passed mint/buy/sell/burn/fee claims, metadata mint+market creation, and blueprint publication/accrual/migration reserve/claim. `scripts/test-graduation-local.mjs` covers blueprint publication, royalty accrual, migration and post-migration claims; it still needs execution against a Meteora DAMM v2 binary compatible with the current source. The pinned Meteora checkout resolves newer Anchor dependencies that the bundled Agave 2.3 SBF Cargo cannot compile without an updated build toolchain.

It cannot safely be deployed for real trading yet: the deployed build now enforces the public treasury `84HCJtzmvWF2tB4SCr8hmDymLN4Rz6u8jJoyaqwLjSRR`, but the RPC market catalogue is not a scalable indexed database; wallet transactions have not been rehearsed on devnet; and the trading program has not had an independent security review. The Meteora ABI is pinned to local upstream commit `a85c926607433f23f0ea60f4ca7b1ae92f4156cb` and needs deployment-version validation. Graduation burns under 0.01% token rounding dust; under 0.01% SOL rounding dust and source-account rent go to the permissionless graduation caller. **The previous handoff archive does not include this prototype and should not be deployed as a trading protocol.**

Checks: TypeScript and build pass in the local sandbox on 2026-10-04. The combined blueprint → Meteora migration → pool swap → fee claim test, wallet/devnet and mainnet transactions, deployed admin persistence, and a browser end-to-end flow have not been verified here.
